# 企业知识库语义检索

## 用法

```bash
node E:/pi/knowledge/search.js "查询内容" [返回条数，默认5]
```

返回 top-k 相关文本块，每条带来源定位（文件 · 表/行号）和相关度（0~1，>0.7 较可信）。
回答用户时**注明来源**（哪个文件哪条记录），相关度低于 0.6 的结果不要采信。

## 知识库维护

- 目录有文件增删改后，重新摄取（增量，按文件 hash，只处理变化的）：
  ```bash
  node E:/pi/knowledge/ingest.js
  ```
- 摄取是离线批处理（百级文件约几分钟），不要在用户等待时随手跑；确需更新时告知用户正在后台摄取。

## 边界

- 这是**语义检索**，擅长"制度怎么规定""哪份文件提到 X"；不擅长精确统计
  （"超标一共有几天"这类应走 device-db / enterprise-data 的 SQL 技能）。
- 监测数据块带有摄取时预计算的"⚠️超标"标记，可直接作为超标证据引用。
- 目前支持 txt/md/csv/docx/xlsx/文字版 PDF；扫描件 PDF 未接入（需 OCR，二期）。
